# The Three Core ERAS Advising Bottlenecks

The user pinpointed three operational bottlenecks in the residency application process: (1) document version fragmentation across Google Docs, (2) advisor review black holes with zero queue visibility, and (3) a fragmented "scavenger hunt" for alumni match data and school lists. This shifts curriculum design immediately to State Machines (pipelines) and Relational Data Models (alumni-to-program linkages).

## Evidence
User shared audio describing:
- Juggling multiple Google Docs versions and emailing drafts to advisors without knowing if or when they are being reviewed.
- The pre-season ERAS gap (ERAS opening in June/July), which forces risky copy-pasting from Google Docs.
- Difficulty discovering past alumni matches and contact information to validate school lists.

## Implications
Session 0002 must teach how software replaces "email + Google Docs" with a deterministic State Machine (`Drafting` → `Submitted` → `In Review` → `Approved`) and how Relational Databases link Alumni to Programs effortlessly.

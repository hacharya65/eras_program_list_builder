# Non-Technical Starting Point and Medical Education Focus

The user established having no prior technical background and aims to create an ERAS medical residency advising web application. Grounding all future architectural concepts in clinical analogies, medical school domain workflows (advisors, students, deans), and high-level product steering is required to keep lessons inside their zone of proximal development.

## Evidence
User stated: *"I have no technical background and am looking to build a web application used to help make advising in prepartion for the medical residency ERAS application a smoother transition."*

## Implications
Rules out raw syntax and terminal-heavy programming tutorials; unlocks product management, data modeling, client-server partitioning, and AI-directed development as the core curriculum.
